# סימולציה חודשית — 27 עובדים

הבדיקה מפעילה את מנוע השיבוץ האמיתי על נתונים סינתטיים, ללא כתיבה למסד הנתונים. חודש מוגדר כ־28 יום: שני שיבוצים של שבועיים. הורצו גם שני שיבוצים נוספים לבדיקת המשכיות בחודש שני.

## הנחות

- 27 עובדים: 4 אחמ״שים, 4 בקרים, 19 מאבטחים. מתוך אלה 8 דתיים: שני אחמ״שים, שני בקרים וארבעה מאבטחים.
- הדתיים זמינים בימי חול. בסוף השבוע הם מגישים רק שבת בלילה, המייצגת מוצ״ש. לא מחושבת שעת צאת שבת; אם משמרת הלילה מתחילה לפניה נדרש כלל זמן נוסף שאינו חלק ממודל המנוע הנוכחי.
- א׳–ה׳: 15 בוקר, 6 ערב, 3 לילה. שישי: 4/2/3. שבת: 2/2/2. דרישות התפקיד כלולות בסך התקנים: אחמ״ש ובקר בבוקר ובערב בימי חול, ובקר או אחמ״ש אחד בלילה. בסופי שבוע הוגדרו תקני מאבטח משום שלא התבקש מינימום מקצועי שם.
- בכל שבוע הוגשו לפחות שתי אפשרויות בוקר ואפשרות ערב, ותוספות אקראיות לפי זרע קבוע. נכללו בוקר וערב יחד ובוקר/ערב/לילה יחד. זמינות חופפת אינה אישור לעקוף מנוחה.
- ההיסטוריה נשמרת בין התקופות. כשההגשה הבאה ידועה ונדרש בוקר ביום הראשון כדי להשלים מינימום, הסימולטור מעביר אותו למנוע כאילוץ גבול עתידי. בלעדיו, מוצ״ש קודם יכול להפוך את המינימום הבא לבלתי אפשרי. זהו חיבור בסימולטור; ממשק המוצר לא שונה.

## תוצאות

נבדקו 44 תקופות: סדרת זמינות מלאה ו־10 סדרות זמינות משתנה, כל אחת בת ארבע תקופות.

| מדד | מנוע קודם | מנוע מתוקן |
| --- | ---: | ---: |
| מקומות לא מאוישים בכל הריצות | 22 | 0 |
| חוסרי מינימום | 0 | 0 |
| הפרות זמינות, דרגה, תקן או מנוחה | 0 | 0 |

בתרחיש המלא אוישו 540/540 משמרות בכל חודש. כל דתי קיבל מוצ״ש אחד בחודש הראשון ועוד אחד בחודש השני. ליתר העובדים היו 2–3 משמרות סוף שבוע בחודש הראשון. אי אפשר לתת לכל 27 העובדים אותו מספר משמרות סוף שבוע: בחודש יש רק 8 מקומות מוצ״ש ל־8 הדתיים ו־52 מקומות סוף שבוע אחרים ל־19 העובדים הנוספים.

בחודש הראשון בתרחיש המלא טווח המשמרות לעובד הוא 19–21, טווח הערבים 4–6 והלילות 2–4. אלה אינם שוויון מושלם או הוכחה לאופטימום. החיפוש מוגבל ומעדיף מינימום וסופי שבוע לפני מדדי איזון אחרים. זמני המנוע על המחשב שנבדק הגיעו לכ־2.8 שניות בתקופה המורכבת ביותר, לעומת עד כ־0.14 שניות קודם; השיפור מוסיף חיפוש לעומת המנוע הקודם.

[דוח אינטראקטיבי לכל העובדים ולכל התרחישים](monthly-scheduler.html) · [צילום חודש ראשון](month-one.png) · [צילום חודש שני](month-two.png).

הדוח מציג סיכומים לכל 44 התקופות ופירוט תאריך, משמרת ותפקיד בפועל לכל עובד בתרחיש המלא. הנתונים המקוריים של מנוע הבסיס, מהקומיט `dea332b`, נשמרו בקובץ `monthly-baseline.json`. לכל מנוע היסטוריה משלו הנובעת מהשיבוצים שיצר; לכן בהמשך החודש ההיסטוריות שונות למרות הגשות זהות.

## שחזור

```sh
pnpm exec tsx scripts/simulate-scheduling.ts /tmp/scheduler-month.json
python3 scripts/render-scheduling-report.py docs/simulations/monthly-baseline.json /tmp/scheduler-month.json
```

פקודת ההרצה מפיקה גם הגשות, משמרות ותפקידים, חוסרים וסטטיסטיקה לכל תרחיש. יצירת הדוח דורשת Python 3 בלבד, ללא חבילות נוספות. אין שינוי סכימה, מיגרציות או נתוני אמת.

בדיקה ממוקדת: `pnpm exec vitest run src/features/scheduling-engine/tests`. כלל הבדיקות שאינן PostgreSQL: `pnpm exec vitest run --exclude 'tests/*-postgres.test.ts'`.
