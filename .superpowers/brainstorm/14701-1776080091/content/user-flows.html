User Flows

Two primary actors, two distinct journeys. Guard flow is mobile-first and minimal. Manager flow is the operational core.

Guard Flow — Availability Submission

1
Log in

Email + password. Manager created the account. Guard lands on their dashboard.

2
See open period

Dashboard shows the active period with dates and submission deadline. Clear CTA: "הגש זמינות" (Submit Availability). If deadline passed, shows read-only submitted data.

3
Fill availability form — 14-day grid

One row per day. For each day, toggle shifts available (Morning / Evening / Night). Per eligible court (if guard works multiple courts, can select court per slot). Unavailable = all off. Mobile-optimized toggle UX.

4
Review & Submit

Summary screen: total days available, shifts per type. Single submit button. Guard can edit freely before deadline.

5
View published schedule

Once manager publishes, guard sees their own assignments for the period: date, court, shift, and whether they have opening duty.

Manager Flow — Schedule Lifecycle

1
Create new scheduling period

Pick start date (Sunday picker only). System calculates 14-day end. Set submission deadline. Status → OPEN. Guards can now submit.

2
Monitor submissions

Dashboard shows submitted vs pending guards. Manager can view each guard's submission. Can close submissions early or extend deadline.

3
Close period & generate draft

Manager clicks "Generate Schedule". Status → CLOSED. Engine runs 3 passes. Returns draft + warnings list. Never overwrites a previously published schedule.

4
Review draft — schedule grid + warnings

14-day grid view: courts as rows (or columns), days across top. Warnings panel alongside. Color-coded cells: filled / understaffed / conflict / opening duty. Manager can re-generate (discards draft and reruns).

5
Manual adjustments

Click any cell to add/remove guard, change opening duty, fill shortages. Live warning updates after each edit. isManualOverride flagged for report transparency.

6
Review summary reports

Per-guard stats: total shifts, morning/evening/night counts, opening duties, weekends, weekly minimum compliance. Fairness distribution overview.

7
Publish

Confirmation dialog. Status → PUBLISHED. FairnessRecord materialized. Guards can now see their assignments. Schedule is locked from further auto-generation (manual edits still possible with audit trail).
