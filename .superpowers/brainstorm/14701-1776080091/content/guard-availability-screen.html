UX Design Notes
Accordion-style days

One day expands at a time. Collapsed rows show a color dot (green = has availability, grey = unavailable) for a quick overview without scrolling through all toggles.

Per-court, per-shift toggles

Only courts the guard is eligible for appear. Tap to toggle. Blue = available, grey = unavailable. Right-to-left order: morning → evening → night (most common first).

Progress indicator

Bottom bar always visible. Shows how many days have been filled. Submit button always accessible — guard doesn't need to scroll to the bottom of 14 rows first.

Auto-save (no draft/submit split)

Toggles save immediately as draft. "הגש זמינות" marks it submitted (locked for manager). Guard sees status badge: Draft / Submitted / Deadline passed.

Fully RTL

Hebrew labels, date names, right-to-left layout throughout. Shift order right-to-left (בוקר / ערב / לילה). No English visible to guards.
